# Vessel

A simple Flutter app that introduces basic laboratory glassware.

## Project Description

Vessel uses a visual guide and tap-to-explore pics to help beginners recognize beakers, graduated cylinders and conical flasks and understand their basic uses.

## Features

- Beaker, graduated cylinder and conical flask information
- Tap a pic to see its capacity, precision, shape and use

## Setup Requirements

- Flutter SDK (includes Dart)
- VS Code or Android Studio
- A connected device, emulator, or Chrome

Check your setup with `flutter doctor`.

## Getting Started

```
git clone https://github.com/banituze/vessel.git
cd vessel
flutter pub get
flutter run
```

## Notes

- Android : Requires the Android SDK and a device or emulator.
- iOS : Requires macOS, Xcode, and an iPhone or simulator.
- Web : Run with `flutter run -d chrome`.
